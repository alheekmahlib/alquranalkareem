## الهدف

ترحيل قسم "تطبيقاتنا" (Our Apps) من الهيكل القديم (GitHub raw JSON بنص واحد عربي) إلى الهيكل الجديد من `https://dash.vexaltech.dev/api/apps` بحيث يعرض **اسم التطبيق وشرحه حسب لغة التطبيق الحالية** (يدعم 11 لغة)، مع إصلاح مسارات الصور النسبية واستخدام `dynamicLink` لزر التحميل.

## الهيكل الجديد للـ API

```json
{
  "apps": [{
    "id": 1,
    "slug": "quran",
    "appName": [{"lang":"ar","name":"..."},{"lang":"en","name":"..."},...],
    "body":      [{"lang":"ar","value":"..."},{"lang":"en","value":"..."},...],
    "companyName": "...",
    "appLogo":   "/media/2026/07/xesesrbr-quran_logo.png",   // مسار نسبي → PNG
    "appBanner": "/media/2026/07/buudwurz-Feature_graphic.png", // مسار نسبي
    "banners": ["/media/...p1.jpg", "..."],
    "dynamicLink": "https://alhikmah.vexaltech.dev/download/quran",
    "urlAppStore": "...", "urlPlayStore": "...", "urlAppGallery": "...", "urlMacAppStore": "...",
    "tags": ["Flutter","Quran"]
  }]
}
```

النقاط الحرجة:
- الاستجابة مغلّفة بـ `{ "apps": [...] }` (ليست Array مباشرة).
- `appName` و `body` مصفوفات ترجمات — نختار العنصر المطابق للغة التطبيق (مع fallback إلى العربية).
- مسارات الصور نسبية — يجب إضافة النطاق `https://dash.vexaltech.dev`.
- الشعار الآن `.png` (ليس `.svg`) → يجب تغيير `SvgPicture.network` إلى `Image.network`.
- `dynamicLink` رابط مطلق جاهز — يُستخدم مباشرة بدل بناء الرابط محلياً.

### 2. `lib/presentation/screens/ourApp/data/models/ourApp_model.dart` (إعادة كتابة كاملة)
نموذج جديد يطابق الهيكل الجديد:
- نماذج مساعدة: `AppTranslation { String lang; String value; }` (تُستخدم لكل من `appName` و`body`).
- الحقول المطلوبة في `OurAppInfo`: `id`, `slug`, `appName` (List<AppTranslation>), `body` (List<AppTranslation>), `companyName`, `appLogo`, `appBanner`, `banners` (List<String>), `dynamicLink`, روابط المتاجر الأربعة.
- `fromJson` يقرأ المصفوفات ويحوّلها.
- **دالة `localizedAppTitle(String langCode)`**: تبحث في `appName` عن العنصر الذي `lang == langCode`، وإن لم تجد ترجع ترجمة العربية، وإن لم تجدها ترجع أول عنصر.
- **دالة `localizedBody(String langCode)`**: نفس المنطق على `body`.
- **دالة `logoUrl` / `bannerUrl` getter**: تُرجع المسار المطلق (`appsMediaBaseUrl + appLogo`) إذا كان نسبياً، أو الرابط كما هو لو كان مطلقاً.

## نقاط سأحرص عليها أثناء التنفيذ
- **التراجع (Fallback) للترجمة**: ترتيب الأفضلية = اللغة الحالية → العربية → أول عنصر متاح (لتجنب الـ crash).
- **معالجة المسار النسبي للمستقبل**: دالة موحدة تتحقق إذا بدأ المسار بـ `http` فترجعه كما هو، وإلا تُضيف المجال.
- **التوافق مع الكاش**: آلية الكاش الحالية (`_box.write(_cacheKey, jsonData)`) ستبقى تعمل لأنها تخزّن JSON الخام ثم تعيد تحليله عبر `fromJson`.
- **تحديث الـ import غير المستخدمة** لتفادي تحذيرات المحلل (lint).
- **التحقق عبر `flutter analyze`** في النهاية للتأكد من عدم وجود أخطاء.

## خارج النطاق (لن ألمسه)
- روابط المتاجر (`urlAppStore` إلخ) وحقول `tags`/`companyName`/`banners` متعددة: محفوظة في الـ model لكن لا تُعرض (كما طلبت — الاسم والشرح والبنر والأيقونة وزر التحميل فقط).
- ملفات الترجمة `.json` (مفاتيح `ourApps`, `download`) تبقى كما هي — الاسم/الشرح يأتون من الـ API الآن وليس من مفاتيح الترجمة.
