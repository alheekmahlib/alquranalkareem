## خطة التنفيذ: إضافة widget مداد بارز تحت HijriWidget

### نظرة عامة
استبدال زر مداد الحالي الموجود في `centerChild` الخاص بـ `TopBarWidget` ببطاقة بارزة مركزية تُوضع **تحت `HijriWidget`** مباشرة في القائمة، مع ترك وسط الشريط العلوي فارغاً.

---

### 1. إنشاء ملف جديد: `lib/presentation/screens/home/widgets/midad_widget.dart`

StatelessWidget باسم `MidadWidget` يطابق لغة تصميم التطبيق. التصميم:

```
╭────────────────────────────────────╮
│                                    │
│            ╭─────────╮             │
│            │   🖊️    │   (دائرة بخلفية accent)
│            ╰─────────╯             │
│                                    │
│           اسأل مداد                 │  ← titleLarge
│       رفيقك لطلب العلم              │  ← titleSmall (midadDescription)
│                                    │
│         ╭──────────╮               │
│         │ اسأل الآن │               │  ← زر pill
│         ╰──────────╯               │
│                                    │
╰────────────────────────────────────╯
```

**مواصفات التصميم (مطابقة لثيم التطبيق):**
- **الخارج:** `Container` بـ `margin: EdgeInsets.symmetric(horizontal: 16.0)`، `borderRadius: BorderRadius.circular(16)` (أكبر من البطاقات العادية 12 ليكون "بارزاً")
- **الخلفية:** `LinearGradient` من `primaryColorLight` بألفا أعلى من البطاقات الأخرى `[.05, .1, .15, .2]` top→bottom لجعلها بارزة بصرياً
- **البطاقة كاملة قابلة للضغط** عبر `GestureDetector` → `Get.to(() => const AiSearchResults(), transition: Transition.fadeIn)` (نفس التنقل الحالي)
- **دائرة الأيقونة:** حاوية دائرية 64×64 بخلفية `primaryColorLight.withValues(alpha: .3)`، تحتوي أيقونة `SvgPath.svgHomeMidadIcon` (ارتفاع 32) ملوّنة بـ `customSvgWithCustomColor`
- **العنوان:** `Text('askMidad'.tr, style: AppTextStyles.titleLarge())` (مفتاح موجود)
- **الوصف:** `Text('midadDescription'.tr, style: AppTextStyles.titleSmall())` (مفتاح موجود)
- **الزر:** حاوية pill بـ `padding: (horizontal: 24, vertical: 8)`، `color: colorScheme.surface.withValues(alpha: .5)`، `borderRadius: 8`، نص `'askNow'.tr` بـ `AppTextStyles.titleSmall()`
- **كل الألوان** عبر `context.theme.*` / `Theme.of(context).colorScheme.*` (لا ألوان ثابتة)
- **النصوص** عبر `AppTextStyles.xxx()` + `.tr`

### 2. تعديل `lib/presentation/screens/home/home_screen.dart`

**أ) إزالة `centerChild` من `TopBarWidget`** (الأسطر 83-118):
```dart
TopBarWidget(
  isHomeChild: false,
  isQuranSetting: false,
  isNotification: true,
  tabBarController:
      GeneralController.instance.state.tabBarController,
  // ← حذف centerChild بالكامل
),
```
الـ `TopBarWidget` يعالج `centerChild == null` بعرض `SizedBox(width: Get.width)` فارغ تلقائياً (مؤكد في `tab_bar_widget.dart:183-186`).

**ب) إضافة `MidadWidget()` تحت `HijriWidget()` في الوضع العمودي** (بعد السطر 38):
```dart
HijriWidget(),
const Gap(16),
MidadWidget(),      // ← جديد
const Gap(16),
QuranSection(),
```

**ج) إضافة `MidadWidget()` تحت `HijriWidget()` في الوضع الأفقي** (بعد السطر 59):
```dart
HijriWidget(),
const Gap(8),
MidadWidget(),      // ← جديد
const Gap(8),
DailyZeker(),
```

**د) تنظيف imports غير المستخدمة** بعد إزالة `centerChild` (قد لا تُستخدم بعد الآن: `customSvgWithCustomColor`, `SvgPath`, `AppTextStyles`, `AiSearchResults` — سأتحقق وأزيل ما لم يعد ضرورياً).
