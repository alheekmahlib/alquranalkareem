## ملخص المهمة

إضافة مفتاحين جديدين إلى 10 ملفات ترجمة (كل اللغات ما عدا العربية التي أُضيفت إليها بالفعل):

- `"booksCount"` ← يقابل `"عدد الكتب"` في العربية
- `"altarajim_waltabaqat"` ← يقابل `"التراجم والطبقات"` في العربية

## البنية الحالية

كل ملف `XX.json` ينتهي حالياً بـ:
```json
  "history": "...",
  "meaning": "..."
}
```

وفي `ar.json` أضاف المستخدم المفتاحين بعد `meaning` مباشرة (مفتاح `meaning` يأخذ فاصلة، ثم المفتاحان، ثم `}`).

## التعديل على كل ملف

استبدال السطر الأخير:
```
  "meaning": "..."
}
```
بـ:
```
  "meaning": "...",
  "booksCount": "<ترجمة>",
  "altarajim_waltabaqat": "<ترجمة>"
}
```
