## 7) قائمة تنفيذ في App Store Connect

1. تحقق أن توطين `ar` و `tr` منشهران (ليسا مسودة) ومحتواهما عربي/تركي سليم.
2. الصق الحقول أعلاه في كل توطين (Name / Subtitle / Keywords / Promotional Text / Description).
3. صفحة es-ES تخدم كل متاجر الإسبانية كاحتياط — لا حاجة لتوطين es-MX منفصل الآن.
4. لا تكرر كلمات العنوان/السطر الفرعي داخل حقل الكلمات، ولا تضع مسافات بعد الفواصل.
5. Promotional Text قابل للتعديل دون مراجعة Apple — استخدمه للمواسم (رمضان، العشر الأواخر).
6. بعد النشر: راقب Performance → Franchise في App Store Connect لقياس أثر التغيير بعد 2-4 أسابيع.
