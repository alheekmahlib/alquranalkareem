# QR Device Sync — Design Spec

التاريخ: 2026-08-24
الحالة: معتمدة
الفرع: `feature/qr-device-sync`

## الملخص

ميزة مزامنة بيانات التطبيق بين أجهزة المستخدم **بدون حساب مستخدم** — الإقران يتم
عبر رمز QR يُعرض مرة واحدة من جهاز ويمسحه بقية الأجهزة، ثم تدوم المزامنة تلقائيًا.
الهوية هي سرّ مشترك (`room_id` بإنتروبيا 128-bit) وليست حسابًا.

## القرارات المعتمدة

| الموضوع | القرار |
|---|---|
| النموذج | مجموعة مزامنة مستمرة (Sync Chain) |
| النطاق | علامات + أذكار + خطط \| موضع القراءة والصوت \| إعدادات المصحف والعرض |
| المستبعدات | سجل البحث، قوائم التشغيل، محادثات AI، حالة الإشعارات (`sn_*`) |
| الخادم | Cloudflare Worker + D1 على حساب المستخدم |
| الأمان | TLS فقط (لا بيانات حساسة)؛ `room_id` هو حامل التفويض + rate limiting |
| التعارض | LWW لكل عنصر عبر `updatedAt` + tombstones للحذف؛ دمج تلقائي صامت |
| التوقيت | إطلاق/عودة للتطبيق + debounce ‏10 ثوانٍ بعد التغيير + زر يدوي |
| دورة الحياة | حتى 5 أجهزة؛ انتهاء بعد 6 أشهر خمول؛ QR قابل لإعادة العرض؛ إعادة تعيين |

## البنية

```
جهاز أ (منشئ)                    Cloudflare Worker + D1                 جهاز ب (منضم)
──────────────                   ──────────────────────                ──────────────
POST /v1/rooms      ──────────►  rooms(id, last_active_at)
QR: alquranalkareem://sync?room=…
                                  devices(room_id, device_id)
مسح QR ──────────────────────────────────────────────────────►  POST /join (snapshot)
POST /changes ◄───── تغييرات ──  changes(room_id, seq, kind,
GET  /changes?since=seq ◄─────    item_key, payload, updated_at,
                                  deleted, device_id)
                     cron يومي: حذف الغرف الخاملة > 6 أشهر
```

## عقد الخادم (v1)

- `POST /v1/rooms` — إنشاء غرفة، يعيد `{room_id}` (16 بايت عشوائية base64url).
- `POST /v1/rooms/:id/join` — انضمام (رفض إذا ≥5 أجهزة)، يعيد snapshot + `latest_seq`.
- `POST /v1/rooms/:id/changes` — دفعة تغييرات (≤500 عنصر / 256KB)، `seq` يتزايد ذريًا.
- `GET /v1/rooms/:id/changes?since=seq` — تغييرات بعد مؤشر معين.
- `GET /v1/rooms/:id` — معلومات الغرفة (عدد الأجهزة، آخر نشاط).
- حدود: ≤10 غرف/IP/يوم؛ كل طلب يحدّث `last_active_at`.
- التوثيق: `room_id` في ترويسة `Authorization: Bearer`.

## نموذج البيانات في التطبيق

- **Drift** (`bookmark_database.dart` v9→v10 و`khatmah_database.dart`): أعمدة جديدة
  `updatedAt` و`deleted` (tombstone) و`syncUuid` (مفتاح مزامنة مستقر لصفوف تفتقد
  مفتاحًا طبيعيًا). كل كتابرة تختم الوقت، وكل قراءة ترشّح `deleted = 0`.
- **GetStorage**: مقاربة فرقية — قائمة allowlist (`sync_constants.dart`) للمفاتيح
  المتتبعة، والمقارنة تجري مقابل آخر snapshot محلي (`SYNC_LAST_SYNCED_KV`) فلا نعدل
  حزمة `quran_library`.
- أنواع العناصر المتزامنة: `bookmark`, `bookmark_ayah`, `adhkar`, `khatmah`,
  `khatmah_day`, `kv`.

## محرك المزامنة (`lib/core/services/sync/`)

دورة المزامنة: سحب (`since` cursor) ← تطبيق LWW محليًا ← دفع تغييرات DB
(عبر `updatedAt`) وفرق KV ← تحديث المؤشر. العمليات idempotent؛ فشل الشبكة يعاد
محاولته عند التريغر التالي (بلا TaskQueue في v1).

الحالة المحلية (GetStorage): `SYNC_ROOM_ID`, `SYNC_DEVICE_ID`, `SYNC_CURSOR`,
`SYNC_LAST_SYNCED_KV`, `SYNC_LAST_AT`.

## الواجهة

- مدخل في شاشة الإعدادات → شاشة مزامنة بحالتين:
  - **بلا غرفة**: زر «إنشاء مجموعة» + «انضمام بمسح QR» + إدخال رمز نصي احتياطي.
  - **نشطة**: QR للإقران (قابل للنساق)، بطاقة عدد الأجهزة وآخر مزامنة، تحديث يدوي،
    مغادرة/إعادة تعيين.
- طلب إذن الكاميرا داخل سياق المسح فقط (موبايل)، والبديل الرمز النصي.
- نصوص موزعة على ملفات اللغات الـ11.

## الأمان والخصوصية

- `room_id` سرّ bearer — لا يُخمّن عمليًا (128-bit) ويُرسل عبر TLS فقط.
- الخادم يرى `room_id` وبيانات غير حساسة (علامات/إعدادات) — بلا PII.
- rate limiting وحدود حجم على مستوى الـ Worker.
- التوكنات (Cloudflare API token) متغيرات بيئة فقط، لا تُكتب في الكود.

## الاختبارات

- Worker: vitest + `@cloudflare/vitest-pool-workers` (مسار سعيد، حد الأجهزة،
  rate limit، عمل `since`).
- التطبيق: اختبارات وحدة لمنطق الدمج (LWW، الحذف لا يعود، فرق KV) والتسلسل —
  بلا شبكة حية.
- تحقق يدوي بين جهازين: إنشاء/انضمام/تغيير/حذف/تعارض بسيط.

## معايير النجاح

1. تغيير يظهر على الجهاز الآخر خلال ≤15 ثانية أثناء الاستخدام، وفورًا عند الفتح.
2. العنصر المحذوف لا يعود بعد المزامنة.
3. حدود Cloudflare المجانية كافية (100k طلب/يوم؛ D1 ~5M قراءة/100k كتابة يوميًا).
